LOGO 形态、品牌三色、字阶、圆角、"格子"App 内 8 处应用

Product · 格子记账 (Ge-zi Ledger) Codename · ledgerly Version · v1.0 2026-10-09 · 首版定稿 📝 状态：LOGO 已定稿，完整 Theme 随 P0 落地

01设计哲学 · 为什么叫"格子" #

1.1 名字与 LOGO 的统一

"格子"不是一个抽象代号 —— 它是 App 内 每一张卡片、每一笔账目、每一个分类、每一份报表的视觉基因。LOGO 用三个圆角方块叠加，App 内所有容器也都沿用"格子"语言，做到图标、UI、品牌叙事三位一体。

1.2 三个圆角方块的隐喻

v6 LOGO 形态（左上 Ink / 右上 Gold / 右下 Teal）

配色位置隐喻
深炭黑 #0F1419左上（最高 z）沉淀的主调；每笔账目都有"沉淀的价值"
金黄 #F5BC1F右上（中层）收入、亮点、关键数字（单位是 ¥，色是金）
明亮 teal #14B8A6右下（底层）增长、复利、流动的现金流

色相与记账语义自然对应：金 = 进账、teal = 流动、炭黑 = 累积。

1.3 设计原则（可落地为 P0 代码评审标准）

  1. 几何优先：所有 UI 元素基于圆角矩形或近似圆，少用尖角斜切
  2. 色块精简：同一屏最多出现 3 种强色 + 中性灰，克制 = 高级
  3. 可识别 > 好看：图标不追求华丽，先追求在小尺寸下还能辨出来
  4. 暗色优先：应用主题支持 dark mode，因个人记账工具有大量"夜间浏览"场景
  5. 格子单位化：间距统一 8 倍数（8 / 16 / 24 / 32…），拒绝任意 px 值

2.1 安全留白（Safe Area）

LOGO 周围至少保留 一个方块边长 25% 的净空，禁止文字侵入。

2.2 最小展示尺寸

  • 主 LOGO 图形：≥ 32px（32px 以下 LOGO 辨识度下降，改用纯文字 wordmark）
  • 文字组合 LOGO（横版）：≥ 96px 宽
  • App 图标提交到 Store：严格 1024×1024 PNG（系统会自动生成所有缩放尺寸）

2.3 禁止事项

❌ 拉伸 LOGO（非等比缩放）

❌ 给 LOGO 加渐变、阴影、描边、内发光

❌ 在饱和度 > 70% 的彩色背景上直接叠加 LOGO

❌ 改 LOGO 配色（品牌资产三色已锁定）

💡 设计取舍：为什么不用"红=支出、绿=收入"的传统映射？

因为 Teal 高亮清爽不刺眼，适合"几乎每天都要看的负面数字"；Gold 自然映射"金钱"；避免红绿色盲用户不适。

04字体（Typography）#

4.1 字体栈

中文

  • iOS / macOS：PingFang SC（系统自带）
  • Android：Noto Sans SC（Google 自带，需打包到 APK）
  • 跨端降级：-apple-system, "PingFang SC", "Noto Sans SC", sans-serif

英文 / 数字（金额、日期）

  • SF Pro（iOS 自带） / Inter / Roboto（跨端）
  • 数字推荐使用 DIN Pro 或 JetBrains Mono 等几何字形，让金额工整

  • 卡片宽度：100% 容器，内 padding space-4 = 16px

06"格子"主题在 App 内的应用点#

这是把"格子"从 LOGO 名字变成 App 视觉灵魂的具体落地清单（P0 到 P3 全部需要遵守）：

6.1 启动屏（Splash Screen）

  • LOGO 居中，深炭黑背景
  • 下方三色横条（高 4px）：从左到右 #0F1419 → #F5BC1F → #14B8A6
  • 屏幕底部 Tagline：小字"格子记账 · 一格一账"或简化 "一格一账"

6.2 主导航 Tab Bar

  • 5 个 Tab：首页 / 流水 / 记一笔 / 报表 / 我的
  • 中央"+"按钮（写一笔）做大色块（Cream #F5F1E8 圆角 24），其他 4 个 Tab 走纯文字
  • 选中状态用 Teal #14B8A6，非选中 #A1A1AA

6.3 卡片（列表项 / 数据卡）

  • 每条流水卡片：r-lg（16）+ 8x8 间距 + 左图标（分类色块）+ 中描述 + 右金额
  • 卡片阴影：不用阴影，只用 1px 描边（gray-200 on Light / gray-600 on Dark）
  • 卡片背景：Light = 白、Dark = #1A1A1A（稍亮于 Ink 背景）

6.4 图表（饼图 / 折线）

  • 饼图色板循环：#F5BC1F → #14B8A6 → #0F1419 → #FFEAA7 → #A7F3E0 → #F5F1E8
  • 折线图主色：Teal #14B8A6，对比线 #F5BC1F
  • 不使用红绿色，统一蓝-金-青-灰体系

6.5 空状态（Empty States）

  • 主页插画 = "几×几的网格矩阵" — 例如 6×6 的小方块，部分被填充，部分空着
  • 中央图标用 LOGO 的简化版（单个圆角方块，金黄）
  • 文案：副标题小字 + 操作按钮（Tap）

6.6 加载 / 错误 / 成功状态

  • Loading：三色横条循环跑马灯，从左滑到右
  • Error：Error Red 边框 + 灰底 X 图标（不是感叹号）
  • Success：Teal #14B8A6 圆环 ✓ 动画

6.7 分类图标（Category Icons）

  • 预定义分类图标采用"几何填充"风格：圆形 / 方形 / 三角 / 菱形 + 配色
  • 用户自定义分类：从预设 8 种几何中选

6.8 主题切换（Settings）

  • Light / Dark / System 三档
  • Dark Mode 启用后：背景变 Ink，所有"炭黑"角色互换为"炭灰"（给文字用）

07可访问性 / 对比度#

7.1 WCAG 2.1 要求

  • 正文文字：对背景 ≥ 4.5:1
  • 大文字（18px+）：≥ 3:1

关键色验证：

组合对比度结论
Charcoal #1F2329 on White #FFFFFF16.6:1✅✅
Teal #14B8A6 on White2.6:1✗ 用于纯文字不可，只允许做按钮 / 图标 / 大字背景
Gold #F5BC1F on Ink #0F141912.4:1✅✅
Cream #F5F1E8 on Ink #0F141916:1✅✅

⚠️ Teal 不能用于纯正文文字！只能做按钮、图标、装饰。如要正文使用，改用 Deep Teal #0F766E（对比度 5.2:1）。

7.2 字号下限

  • 正文 body = 15px（P1 老年模式可放大到 17）
  • 永远不要小于 caption = 12px

7.3 触摸目标

  • iOS / Material 一致：最小 44 × 44 pt
  • 主操作按钮：≥ 48 × 48 dp
